## 🛠 安装方法（Lightroom Classic / Lightroom CC）

### 方法一：双击导入（推荐）
1. 解压本压缩包
2. 双击任意 `.xmp` 文件 → 自动导入 Lightroom 预设面板
3. 或：Lightroom → 编辑 → 首选项 → 预设 → 显示 Lightroom 预设文件夹 → 将 `.xmp` 放入 `Develop Presets` 文件夹 → 重启 LR

### 方法二：手动拖入
- 打开「修改照片」模块 → 左侧预设面板 → 右键 → 新建预设文件夹 → 将 `.xmp` 拖入该文件夹

### 使用方法
1. 导入 RAW/JPG 照片，进入「修改照片」模块
2. 点击预设名称一键应用
3. 按需微调曝光、色温（每张照片光线不同，建议以预设为起点 ±0.2EV 微调）

## 📝 使用建议

- **直播/会议（顶光、混合色温）**：先用白平衡吸管校正色温，再套用预设效果最佳
- **人像**：套用后如肤色过暖，将「橙色饱和度」向 -5 方向微调
- **批量处理**：选中多张照片 → 同步设置 → 全选应用，一分钟处理 100+ 张
