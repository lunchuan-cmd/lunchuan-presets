## 🛠 安装方法

### Lightroom Classic
1. 下载 zip 并解压
2. 打开 Lightroom Classic → 编辑 → 首选项 → 预设 → 勾选"显示 Lightroom 预设文件夹"
3. 将 `.xmp` 文件复制到弹出的文件夹中的 `Develop Presets` 目录
4. 重启 Lightroom，在「修改照片」→ 预设面板即可看到

### Lightroom CC / 移动端
1. 解压后双击 `.xmp` 文件 → 自动导入预设
2. 或在「修改照片」→ 预设 → 右上角 `⋮` → 导入预设

### 使用方法
1. 导入 RAW/JPG 照片，进入「修改照片」模块
2. 点击预设名称一键应用
3. 建议以预设为起点 ±0.2EV 微调曝光（每张照片光线不同）
4. 批量处理：选中多张 → 同步设置 → 全选应用，**100 张照片 1 分钟出片**

## 📝 场景建议

- **直播/会议（顶光、混合色温）**：先用白平衡吸管校正色温，再套用预设
- **人像**：套用后若肤色过暖，将「橙色饱和度」向 -5 方向微调
- **活动大合影**：用 `Portrait_Skin` + 同步设置，肤色统一且通透
